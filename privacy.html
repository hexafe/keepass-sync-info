KeePass Sync

Privacy policy

Effective date: 5 November 2026. This policy describes a personal synchronization configuration operated by its owner.

Data accessed and purpose

The local synchronizer accesses encrypted KeePass database files and associated Google Drive metadata, including file names, identifiers, checksums and modification information. It uses this data only to synchronize the owner's database, detect conflicts and preserve recoverable encrypted versions.

The Google OAuth permission grants read and write access to Google Drive. The installed configuration limits routine synchronization to the selected database and synchronization control files; the OAuth permission itself is broader than that configured file selection.

Storage and transfer

The encrypted database is stored on the owner's computer, in the owner's Google Drive and in compatible applications on the owner's devices. Encrypted version backups and synchronization status are stored locally. OAuth client credentials and refresh tokens are stored in a file restricted to the owner's local user account.

The synchronizer does not decrypt database entries and does not collect the master password. Google processes API requests under the owner's authorization. Compatible password applications manage unlocking on the owner's devices.

Sharing and retention

The configuration does not sell data, use it for advertising, or send database content to analytics services. It transfers the selected encrypted files between the owner's devices and Google Drive. Local backups remain until the owner removes them; Google Drive may retain file revisions and deleted items under its own settings.

Owner control

The owner can stop synchronization, remove local backups, manage files in Google Drive and revoke the application's access in Google Account settings. Revoking access does not itself delete existing files or backups.

This information website

This static website does not receive OAuth tokens, passwords or database content. It contains no analytics scripts, forms or application login. Its hosting provider may process ordinary website access logs.
