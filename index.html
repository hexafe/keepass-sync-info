KeePass Sync

A personal configuration for synchronizing an encrypted KeePass database between its owner's computer and Google Drive. Compatible mobile applications can open the same database from Google Drive.

Synchronization runs locally on the owner's computer using rclone. Google OAuth authorizes that local program to access the owner's Google Drive account. The configuration processes the selected encrypted database and synchronization control files.

The synchronizer does not unlock the database and does not receive its master password. Encrypted version backups are retained on the owner's computer. Concurrent edits can require the owner to merge preserved database versions.

This application is for its owner's personal use. It is not a hosted password-management service.
