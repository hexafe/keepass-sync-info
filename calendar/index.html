Personal Calendar for Omarchy

A personal desktop integration that displays Google Calendar events in the Omarchy calendar widget.

How it works

The integration requests read-only access to calendars available to the signed-in Google account. It retrieves calendar and event information to display a calendar and upcoming events on the user's computer. It does not create, edit, or delete calendar events.

The integration runs locally and stores a local copy of event information for the widget. This informational website does not collect calendar data.

Learn more about data handling in the privacy policy.
