Privacy policy

Last updated: November 5, 2026.

Personal Calendar for Omarchy is a personal desktop integration that displays Google Calendar events on the user's computer.

Data accessed and purpose

With the user's permission, the integration uses the Google Calendar read-only scope to read the calendars available to the account and event details such as titles, times, locations, calendar names and links. These details are used to display a calendar and upcoming events. The integration does not create, modify, or delete calendar events.

Storage and sharing

The integration runs on the user's computer. It saves a local event data file for the Omarchy widget and stores authorization credentials locally using the Google Workspace CLI. Google receives API requests needed to authenticate and retrieve the data. This informational website does not receive calendar events or credentials. The integration does not send calendar data to a separate application server.

Retention and control

The local event file is refreshed when synchronization succeeds and remains on the computer until replaced or deleted. The user can stop the sync, remove the local event file and local credentials, and revoke access through their Google Account's third-party connections settings.
